# Notice

EVE-APM Mac is an independent macOS application. It shares no code with the
projects below, but it follows the feature set and the naming they established.

- [EVE-APM Preview](https://github.com/mrmjstc/eve-apm-preview) by mrmjstc,
  MIT licensed. The Windows application whose features this one reproduces,
  including the `eveapm://` link scheme.
- EVE-O Preview and EVE-X Preview, the tools that established multi-client
  thumbnail previews for EVE Online.

The application icon is the helmeted bee that EVE-APM Preview ships as
`bee.png`, redrawn onto a rounded square by `scripts/make-icon.swift`. It is the
mascot EVE players associate with Goonswarm Federation, and it is used here for
the same reason the upstream project uses it: continuity for the players who
already know the tool. It is not an original work of this project, and anyone
redistributing a fork may prefer to replace it.
